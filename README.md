# homebrew-tap
Homebrew tap for anycloud

```sh
brew tap anycloud-sh/tap
brew install anycloud
brew install backmesh
```

`brew upgrade anycloud` and `brew upgrade backmesh` move to the latest release. backmesh runs CI runners for GitHub Actions in your own cloud, on anycloud. If another tap also has a formula with one of these names, use the full name, such as `anycloud-sh/tap/backmesh`.
